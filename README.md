# Gas Rapids

A four-player, fart-powered raft race for the browser. Four animals share one round raft; each player has one fart button. Farting pushes the raft away from your seat, so the back seat drives, the side seats steer, and the front seat brakes. Fart together at the right moment or spin into the spikes.

It is a from-scratch recreation of the mechanic in *Fart Together* (GamesMrkt, 2026), built entirely with free tools. Nothing here is copied from that game: all models, sounds and levels are generated by code in this repo.

## Run it

```bash
npm install
npm run dev
```

Open the printed `localhost` URL. `npm run build` writes a static site to `dist/` that can be hosted anywhere for free (GitHub Pages, Netlify, Cloudflare Pages, itch.io).

## Controls

| Seat | Animal | Fart | Aim |
|------|--------|------|-----|
| Back | Hippo | Space | A / D |
| Right | Capy | Enter | Left / Right arrows |
| Front | Croc | V | C / B |
| Left | Bear | P | O / [ |

- Press your fart key on the title screen to take a seat. Seats nobody takes are driven by bots (toggle on the title screen).
- Tap for a short "pop" burst, hold for sustained thrust. The gas bar drains while you hold and refills when you stop. Run it to zero and you sputter until it recovers.
- Aim rotates your jet: on the back and front seats D steers the raft right; on the side seats D pushes the raft forward.
- Gamepads: pad 1 to 4 map to seats 1 to 4. A or right trigger farts, left stick or bumpers aim.
- Touch (phones): tap the middle of the screen to fart, the left or right thirds to aim. Touch always drives the back seat.
- Esc returns to the menu.

## Play online with friends (voice included)

1. Click **Play online with friends**, type a name, **Create party**. You get a 5-letter code and an invite link.
2. Send the link. Friends open it, type a name, press **Join**. Up to four people; seats fill in join order and any empty seat is a bot.
3. Everyone's microphone turns on when they enter the party (the browser asks once). The 🎤 button or the **M** key mutes. Avatars pulse while someone talks.
4. The host picks the level and presses **Start race**. Online, every player drives their own seat with Space + A/D (or any seat's keys, a gamepad, or touch).

How it works, and why it costs nothing: the host's browser runs the race. Each friend's browser sends button presses to the host and gets back the raft state 30 times a second, directly over a WebRTC data channel. Voice goes browser to browser the same way, one audio link per pair of players. There is no game server to rent. The only outside service is the public PeerJS broker, which introduces the browsers to each other once and then drops out. If a friend on a very strict network cannot connect, Cloudflare's TURN relay has a free tier and `coturn` runs on Oracle Cloud's free VM; both are optional.

The `localhost` address only works on your own computer. To play with friends the site has to be on a public HTTPS address (microphones require HTTPS). See **Deploy for free** below.

## Deploy for free

Two hosts are set up. Both cost nothing.

**Cloudflare + your own broker (the main one, commercial use is allowed)**

Live at **https://play.gas-rapids.workers.dev**. Broker at `https://gas-rapids-broker.gas-rapids.workers.dev`.

```bash
npx wrangler login          # once, opens the browser; a free Cloudflare account is enough, no card
npm run deploy              # deploys the broker worker, then builds and deploys the site
```

`wrangler.jsonc` at the root serves `dist/` as a Worker with static assets (Cloudflare has folded Pages into Workers). `.env` holds `VITE_PEER_HOST`, the broker's host, which is baked into the build so the game uses your broker instead of the public PeerJS one.

The broker in `server/` is a 90-line Cloudflare Worker that speaks the PeerJS signaling protocol. It only relays the connection handshake; game data and voice never touch it, so the free plan's limits are nowhere near.

**GitHub Pages (fallback, non-commercial)**

The workflow in `.github/workflows/pages.yml` publishes every push to `main` at `https://abbasaliii.github.io/gas-rapids/`.

**Also free:** itch.io (zip `dist/` and upload as an HTML game, lets you charge for it), Netlify.

**Play right now without deploying:** run `npm run dev`, then expose it with a free tunnel such as `winget install Cloudflare.cloudflared` + `cloudflared tunnel --url http://localhost:5173`. The tunnel prints a temporary public HTTPS link that works while your PC is on.

## Hazards

Spiked buoys and spinning spike rollers pop the raft and send you back to the last checkpoint (the retry counter goes up). Fences only bounce you. Chevron water is a fast current. Checkpoints and the finish line are the arches.


### Physics model

The raft is a 2D rigid body on the water plane (position, yaw, velocity, angular velocity). Each seat sits on the rim at 90 degree spacing. A farting player applies a force at their seat position pointing toward the raft's centre, rotated by their aim. Because the force acts off-centre, aimed farts also produce torque. Drag is linear plus a small quadratic term, a weak "keel" turns the raft to face its motion, and the river current pushes along the course tangent. The course is a sampled centre line with a half-width at every metre, so walls, lateral position and progress are all cheap lookups.

### Adding a level

Add an entry to `src/levels.js`. A level is a list of segments walked in order: `len` metres, `turn` degrees (positive = right), `w` half-width at the end of the segment, and `f` features (`buoy`, `roller`, `gate`, `checkpoint`, `boost`, `spikes`, `finish`). Keep at least 7 m of open water past any lethal hazard; the raft is about 5 m across.

## Debug hook

`window.gasRapids.tick(seconds)` advances the game without waiting for animation frames and `window.gasRapids.state` exposes the live game. This is how the race is simulated end to end in automated checks.

## Roadmap

1. Online polish: client-side prediction of your own fart puff so it appears before the host confirms it, reconnect on dropped links, kick/seat-swap in the lobby.
2. Character models: swap the primitive animals for CC0 rigged animals (Quaternius, Kenney) loaded with GLTFLoader.
3. More hazards from the original: spiral tubes, swinging hammers, waterfalls, half-pipe slides.
4. Competitive mode: two rafts on one course.
5. Ship: `npm run build`, upload `dist/` to itch.io or GitHub Pages. Steam needs the one-off Steam Direct fee, so it is the only non-free step and is optional.
